# MACHINE LEARNING REGRESSION MODEL FOR WEATHER AND AQI PREDICTION

## PROJECT OVERVIEW

THIS PROJECT INVOLVES TRAINING MULTIPLE REGRESSION MODELS TO PREDICT THE AIR QUALITY INDEX (AQI) BASED ON WEATHER DATA. THE DATA INCLUDES PARAMETERS SUCH AS TEMPERATURE, HUMIDITY, PRESSURE, PM 2.5, PM 10, BAROMETER, AND MORE. THE WORKFLOW IS DIVIDED INTO THREE NOTEBOOKS:

- **Main[1]**: DATA CLEANING, EXPLORATORY DATA ANALYSIS (EDA), AND VISUALIZATION
- **Main[2]**: FEATURE SELECTION, CORRELATION ANALYSIS, AND AQI TARGET ENGINEERING
- **Main[3]**: MODEL TRAINING, OPTIMIZATION, AND EVALUATION

THE MODELS WERE TRAINED USING CLASSICAL MACHINE LEARNING REGRESSORS INCLUDING RANDOM FOREST, XGBOOST, LIGHTGBM, AND CATBOOST. EVALUATION WAS PERFORMED USING METRICS SUCH AS **R²**, **MEAN SQUARED ERROR (MSE)**, AND **MEAN ABSOLUTE ERROR (MAE)**.

---

## MODEL DETAILS

- **FEATURE ENGINEERING:**
  - REMOVAL OF NON-NUMERIC ENTRIES AND NULL VALUES
  - TIME-BASED FEATURES SUCH AS HOUR, DAY, AND MONTH EXTRACTED
  - AQI TARGET SHIFTED FORWARD TO PREDICT FUTURE VALUES

- **PREPROCESSING:**
  - DATA SCALING USING MINMAXSCALER
  - ONE-HOT ENCODING OF CATEGORICAL FEATURES

- **EVALUATION METRICS:**
  - **R² SCORE** TO EVALUATE MODEL FIT
  - **MEAN SQUARED ERROR (MSE)**
  - **MEAN ABSOLUTE ERROR (MAE)**

---

## MACHINE LEARNING MODELS USED AND COMPARED

THE FOLLOWING MACHINE LEARNING MODELS WERE USED AND COMPARED DURING THE TRAINING PHASE:

1. **RANDOM FOREST REGRESSOR**  
   - ENSEMBLE METHOD BASED ON MULTIPLE DECISION TREES  
   - HYPERPARAMETERS OPTIMIZED VIA GRID SEARCH

2. **XGBOOST REGRESSOR**  
   - BOOSTING ALGORITHM THAT BUILDS MODELS IN SEQUENCE TO MINIMIZE ERROR  
   - CONFIGURED WITH 500 ESTIMATORS AND LEARNING RATE OF 0.05

3. **LIGHTGBM REGRESSOR**  
   - FAST GRADIENT BOOSTING FRAMEWORK WITH HISTOGRAM OPTIMIZATION  
   - TRAINED WITH 500 ESTIMATORS AND MAX DEPTH 6

4. **CATBOOST REGRESSOR**  
   - BOOSTING METHOD THAT HANDLES CATEGORICAL FEATURES WITHOUT MANUAL ENCODING  
   - TRAINED WITH 500 ITERATIONS, LEARNING RATE 0.05

## TRAINING THE MODEL

1. **LOAD AND CLEAN DATA**  
   THE RAW DATA IS CLEANED TO REMOVE NON-NUMERIC ENTRIES LIKE `"--"` AND UNNECESSARY COLUMNS.

2. **FEATURE ENGINEERING**  
   FEATURES ARE SELECTED BASED ON PEARSON CORRELATION. TIME-BASED FEATURES ARE GENERATED. AQI IS SHIFTED TO CREATE A FUTURE PREDICTION TARGET.

3. **MODEL INPUTS**  
   FEATURES ARE SCALED USING MINMAXSCALER AND SPLIT INTO TRAIN/TEST SETS USING AN 80:20 RATIO.

4. **MODEL TRAINING**  
   EACH REGRESSOR IS TRAINED ON THE SAME DATA SPLIT. RANDOM FOREST IS TUNED USING GRIDSEARCHCV. THE REST ARE TRAINED WITH PRE-DEFINED HYPERPARAMETERS.

5. **EVALUATION**  
   MODELS ARE EVALUATED USING R², MSE, AND MAE METRICS ON TEST DATA.

---

## RESULTS

THE MODELS’ PERFORMANCE WAS MEASURED USING THE FOLLOWING METRICS:

- **R² SCORE** - TO MEASURE HOW WELL THE PREDICTED AQI MATCHES ACTUAL VALUES
- **MEAN SQUARED ERROR (MSE)** - TO PENALIZE LARGE ERRORS
- **MEAN ABSOLUTE ERROR (MAE)** - TO UNDERSTAND AVERAGE PREDICTION ERROR

EACH MODEL’S METRICS WERE LOGGED AND COMPARED TO IDENTIFY THE BEST PERFORMER. ADDITIONALLY, ACTUAL VS PREDICTED AQI PLOTS AND SCATTER PLOTS WERE GENERATED TO VISUALIZE ACCURACY.

---

## CONCLUSION

THIS PROJECT DEMONSTRATES HOW MACHINE LEARNING MODELS CAN BE USED TO PREDICT AIR QUALITY INDEX BASED ON WEATHER CONDITIONS. AMONG THE MODELS TESTED, ENSEMBLE REGRESSORS SUCH AS RANDOM FOREST, XGBOOST, LIGHTGBM, AND CATBOOST PROVIDED HIGH PREDICTION ACCURACY. THE RESULTS INDICATE STRONG POTENTIAL FOR USING MACHINE LEARNING IN ENVIRONMENTAL FORECASTING SYSTEMS.
